단계 ③: 패치 화소를 일렬로 이어 붙여 3ℎ𝑤/𝑝^2  차원 벡터로 만듦. 임베딩층을 통해 𝑑_𝑚𝑜𝑑𝑒𝑙 차원으로 변환. 𝑑_𝑚𝑜𝑑𝑒𝑙 차원 벡터를 행에 쌓으면 𝑝^2×𝑑_𝑚𝑜𝑑𝑒𝑙=𝑇×𝑑_𝑚𝑜𝑑𝑒𝑙 크기 행렬 𝐒가 됨
단계 ④: 위치 인코딩 행렬 𝐏를 만들고 𝐒에 더하여 행렬 𝐗를 만듦

DETR의 원리
트랜스포머는 턴서가 𝑇×𝑑_𝑚𝑜𝑑𝑒𝑙 크기를 유지하면서 흐르기 때문에 컨볼루션 신경망에 비해 개조할 수 있는 여지가 적음
DETR은 트랜스포머의 원래 구조를 유지하면서 박스 집합을 예측할 수 있게 개조됨
영상을 입력으로 받아 박스 집합을 출력해야 하므로 인코더와 디코더를 모두 사용
디코더에 붙은 출력층은 𝑇〖×𝑑〗_𝑚𝑜𝑑𝑒𝑙 텐서를 박스 집합으로 변환해야 함
손실 함수는 예측 박스 집합과 레이블 박스 집합이 일치하는 정도를 측정해야 함

모듈 ①
컨볼루션 신경망으로 𝑚×𝑛×3 컬러 영상을 ℎ×𝑤×𝐶의 특징 맵으로 변환
논문의 실험에서는 𝐶=2048, ℎ=𝑚/32, 𝑤=𝑛/32
결과 특징 맵에 1 × 1 컨볼루션을 적용하여 𝐶 차원을 𝑑_𝑚𝑜𝑑𝑒𝑙 차원으로 변환하여 〖ℎ𝑤×𝑑〗_𝑚𝑜𝑑𝑒𝑙=〖𝑇×𝑑〗_𝑚𝑜𝑑𝑒𝑙 행렬을 얻음
이 행렬이 인코더의 입력이 됨

모듈 ②
인코더 블록
모듈 ①이 만든 〖𝑇×𝑑〗_𝑚𝑜𝑑𝑒𝑙 행렬을 입력 받아 위치 인코딩 적용하여 인코더 블록에 입력

디코더 블록
자기 회귀를 적용할 수 있을까? 박스 집합은 순서가 없기 때문에 불가능
object queries라는 〖𝐾×𝑑〗_𝑚𝑜𝑑𝑒𝑙 행렬을 입력 받음 (𝐾는 발생 가능한 물체의 최대 개수)
출력층은 물체가 아닌 경우 ∅ 표시된 박스를 출력하여 가변 개수의 물체를 검출 ([그림 11-19] 예에서는 두 개의 박스와 세 개의 ∅ 출력)
object queries는 학습 초기에 아무런 정보가 없기 때문에 위치 인코딩 𝐏를 가지고 출발

모듈 ③
〖마지막 디코더 블록이 출력한 𝐾×𝑑〗_𝑚𝑜𝑑𝑒𝑙 행렬의 각 행을 FF층에 통과시켜 박스로 변환

웹에서 자동 수집 방법이 새로운 길 제시. CLIP은 새로운 길 닦은 선구적인 모델
CLIP의 학습
웹에서 (image,text) 샘플을 4억 장 가량 모아 학습에 사용([그림 11-26])
n개 샘플에서 모든 image와 모든 text를 쌍으로 맺으면, n개는 옳은 쌍이고 나머지 n2-n개는 틀린 쌍
옳은 쌍의 코사인 유사도 최대화하고 틀린 쌍 최소화하게 대조 학습contrastive learning 적용
CLIP과 ResNet50 겨룬 결과
ResNet50은 사람이 정교하게 레이블링한 데이터셋으로 학습하고 CLIP은 웹에서 자동 수집한 데이터셋으로 학습했음에도 불구하고
ImageNet 데이터셋에서 CLIP이 1.9%만큼 우월
27개 데이터셋에서 실험한 결과 CLIP이 16개에서 우월

스탠퍼드 대학의 Human-centered AI 연구소는 이런 현상을 토대 모델foundation model이라는 새로운 조류로 설명

장거리 의존long-range dependency
CNN은 깊은 층을 거쳐 공간 의존성 처리


RNN은 시간 의존성 처리
“우리는 __에서 배불리 먹고 실컷 놀다 배를 마을로 날랐다‘ 문장에서 빈 곳이 강일 때와 농장일 때 배의 의미가 달라짐

트랜스포머는 자기 주목을 통해 명시적으로 장거리 의존 처리
나말고 다른 단어와의 연관성을 통해 가장 주목해야할걸 찾는다
지역,젼역 정보를 모두 능훅하게 처리하는 트랜스포머

확장성
자연어 처리 분야에서 트랜스포머는 확장성 경쟁 중
원래 트랜스포머는 4000만(40Mega) 조금 넘는 가중치를 가졌는데, GPT-3은 1750억(175Giga), Switch 트랜스포머는 1.6조(1.6Tera)개의 가중치. GPT-4는 더욱 커질 전망
자연어 처리에서 모델 크기, 데이터 크기, 계산 자원 사이의 관계를 체계적으로 실험 분석한 결과, 큰 스케일을 사용하는 것이 유리하다는 결론
컴퓨터 비전 분야의 확장성
컴퓨터 비전에서도 모델이 클수록 좋을까?
5백만~20억 개 매개변수를 가진 트랜스포머를 3천만~30억장 데이터셋으로 확장성 실험한 결과, 모델 크기와 데이터 크기, 계산 자원을 함께 늘리면 성능 향상
모델 크기를 작게 하면 병목으로 작용(데이터셋을 확장해도 성능 향상 없음)

설명 가능
인간은 뛰어난 설명 능력을 갖춤
컴퓨터 비전의 설명 가능 기존 연구: CNN을 위한 CAM과 GradCAM
트랜스포머는 설명 가능에 유리할까? 그렇다.
자기 주목 행렬을 활용하면 더 쉽게 더 정확하게 설명 가능함
예) DETR의 설명 가능([그림 11-20])
예) 미세 분류fine-grained classification하는 TransFG([그림 11-30]): 부리나 코끝처럼 특정한 곳에 집중


멀티 모달
모든 기계학습 모델은 귀납 편향inductive bias을 가짐
“The inductive bias (also known as learning bias) of a learning algorithm is the set of assumptions that the learner uses to predict outputs of given inputs that it has not encountered.” (Wikipedia)

트랜스포머의 귀납 편향은 약한 편 -> 여러 입력 형태에 적용 가능, 즉 멀티 모달에 유리
CLIP: 영상과 문장을 주면 문장의 적합한 정도를 출력
DALL·E: 자연어 문장을 주면 영상 생성(13장)
METER: 컴퓨터 비전과 자연어 처리에 두루 활용 가능한 사전 학습 모델


토대 모델로서 역할
스탠퍼드 대학의 인간중심 인공지능연구소Stanford Institute of Human-centered Artificial Intelligence는 2021년 논문에서 토대 모델foundation model이라는 개념 제안
건축물 토대는 완성된 집이 아니지만 다양한 형태의 집을 올릴 수 있는 가능성 제공
토대 모델은 전이 학습을 통해 많은 하위 과업downstream task에 적용할 가능성
트랜스포머는 토대 모델에 적합
약한 귀납 편향으로 인해 다중 모달에 유리
장거리 의존과 확장성으로 인해 높은 성능
설명 가능에 유리
